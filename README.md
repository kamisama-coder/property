# AI Property Search & Ranking

**AI Property Search & Ranking** is an advanced platform for discovering and evaluating properties. It has two distinct systems: an **AI-powered search engine** for finding properties based on text or image descriptions, and a **ranking system** that scores and ranks properties according to user queries.

## Key Features

### AI-Powered Search Engine
- Search properties using natural language queries.  
- Find properties based on image descriptions.  
- Supports multiple simultaneous queries for comprehensive results.  

### Property Ranking System
- Dynamically ranks properties based on relevance to user queries.  
- Handles multiple criteria for ranking, including text and image-based features.  
- Allows users to prioritize results according to their preferences.  

## How It Works

1. **Search Input**: Users provide text queries or upload images.  
2. **Search Engine Processing**: AI models retrieve relevant properties matching the query or image description.  
3. **Ranking**: Retrieved properties are scored and ranked based on relevance and user-specified criteria.  
4. **Results**: Ranked properties are presented to the user for selection.
